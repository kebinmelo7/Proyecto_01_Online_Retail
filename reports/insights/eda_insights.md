# Insights del análisis exploratorio

## Evolución de las ventas

Las ventas presentan variaciones importantes durante el periodo analizado. 
El crecimiento más destacado se observa durante los últimos meses de 2011, 
alcanzando su mayor valor en noviembre con aproximadamente $1.46 millones.

## Distribución geográfica

El Reino Unido concentra la mayor parte de las ventas, con aproximadamente 
$8.17 millones registrados. Esto representa cerca del 84 % del valor total 
de las ventas y evidencia una fuerte dependencia del mercado británico.

## Productos

El producto con mayor valor de ventas es el REGENCY CAKESTAND 3 TIER, 
con $164,459.49.

Sin embargo, el producto que concentra el mayor número de unidades vendidas 
es WORLD WAR 2 GLIDERS ASSTD DESIGNS, con 53,751 unidades.

Esto demuestra que los productos con mayor volumen de unidades no necesariamente 
son los que generan mayores ingresos.

## Clientes

El cliente 14646 presenta el mayor valor de compras, con $279,489.02.

Los 10 principales clientes representan el 16.53 % de las ventas asociadas 
a clientes identificados, lo que indica que existe concentración en clientes 
de alto valor, aunque las ventas no dependen exclusivamente de un grupo reducido.

## Ticket promedio

El ticket promedio considerando todas las facturas es de $375.52.

Al considerar únicamente las facturas con valor positivo, el ticket promedio 
aumenta a $533.17.

Esta diferencia refleja el impacto de las devoluciones y ajustes sobre el 
valor promedio de las facturas.

## Devoluciones

El valor de las operaciones negativas representa aproximadamente el 8.61 % 
del valor de las ventas positivas.

Este indicador muestra que las devoluciones y ajustes tienen un impacto 
relevante sobre el comportamiento comercial registrado.
